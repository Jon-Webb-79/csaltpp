Allocates memory aligned to the specified boundary. The alignment must be a power of 2. If alignment is 0, uses default\+\_\+alignment\+\_\+.

Implementation strategy\+:
\begin{DoxyItemize}
\item If alignment $<$= max\+\_\+align\+\_\+t\+: uses operator new
\item If alignment $>$ max\+\_\+align\+\_\+t\+: uses posix\+\_\+memalign (POSIX) or \+\_\+aligned\+\_\+malloc (Windows)
