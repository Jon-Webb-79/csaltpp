Allocate aligned memory from the arena
\begin{DoxyParams}{Parameters}
{\em bytes} & Number of bytes to allocate \\
\hline
{\em alignment} & Required alignment in bytes (must be power of 2, 0 = use default) \\
\hline
{\em zeroed} & If true, zero-\/initialize the allocated memory (default\+: false)\\
\hline
\end{DoxyParams}
\begin{DoxyReturn}{Returns}
Expected containing pointer to aligned memory on success, or error on failure
\end{DoxyReturn}

\begin{DoxyExceptions}{Exceptions}
{\em Never} & throws -\/ returns Expected with error on failure\\
\hline
\end{DoxyExceptions}
Like alloc(), but ensures the returned pointer is aligned to the specified boundary. If alignment is 0, uses the arena\textquotesingle{}s default alignment. If alignment is not a power of 2, it is automatically rounded up to the next power of 2.

The alignment requirement may cause padding to be inserted, which counts against the arena\textquotesingle{}s capacity but isn\textquotesingle{}t directly usable.

\hline
{\em Expected} & with Alignment\+Error if alignment normalization fails \\
\hline
{\em Expected} & with Memory\+Error if out of space or allocation fails \\
\hline
{\em Expected} & with Length\+Overflow\+Error if size calculations overflow\\
\hline
\end{DoxyRetVals}
