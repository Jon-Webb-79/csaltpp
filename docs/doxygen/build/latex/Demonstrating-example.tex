No-\/op for arena allocators (individual deallocation not supported)

Arena allocators do not support individual deallocation. All memory is freed together via reset() or when the arena is destroyed. This method is a no-\/op to maintain compatibility with the Allocator interface.

This design is intentional and provides\+:
\begin{DoxyItemize}
\item Much faster allocation (no per-\/allocation metadata)
\item No fragmentation
\item Simpler implementation
\item Better cache locality
\end{DoxyItemize}

\begin{DoxyNote}{Note}
To free memory, use reset() to free all allocations, or restore() to rollback to a checkpoint, or let the arena be destroyed.
\end{DoxyNote}
