\begin{DoxyWarning}{Warning}
Never call \+::operator delete directly on a Pool\+Allocator created by a factory method. Always use Pool\+Deleter or let Unique\+Ptr handle it.

For Stack pools, ensure the buffer outlives the pool. The deleter doesn\textquotesingle{}t free the buffer (user owns it), but the pool must be destroyed before the buffer goes out of scope.
\end{DoxyWarning}
