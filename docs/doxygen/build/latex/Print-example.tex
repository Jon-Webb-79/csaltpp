Writes human-\/readable statistics about the Heap\+Allocator to the provided buffer. Since Heap\+Allocator doesn\textquotesingle{}t track allocations, the statistics primarily describe the allocator type and configuration.

Returns false if\+:
\begin{DoxyItemize}
\item buffer is nullptr
\item buffer\+\_\+size is 0
\item buffer is too small for the statistics string
\end{DoxyItemize}
