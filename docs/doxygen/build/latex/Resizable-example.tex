Creates a pool that owns its own dynamic arena. The pool can optionally grow by allocating additional chunks as needed.

If prewarm=true, allocates the first chunk immediately so the first allocation is guaranteed O(1). If prewarm=false and grow\+\_\+enabled=false, the pool will be unusable.
