Creates a fixed-\/capacity pool using a user-\/provided buffer. The pool does NOT own the buffer. The buffer must remain valid for the pool\textquotesingle{}s lifetime.

The pool creates a static arena within the buffer, then allocates all blocks from that arena. Cannot grow.
