Enable or disable arena resizing
\begin{DoxyParams}{Parameters}
{\em toggle} & If true, enable resizing; if false, disable resizing\\
\hline
\end{DoxyParams}
Dynamically enables or disables the arena\textquotesingle{}s ability to grow by allocating additional chunks. Only works for DYNAMIC arenas that own their memory. Has no effect on STATIC or SUB arenas (they cannot resize regardless).

Useful for\+:
\begin{DoxyItemize}
\item Enforcing strict memory limits during critical sections
\item Testing allocation failure handling
\item Preventing unbounded growth
\end{DoxyItemize}
