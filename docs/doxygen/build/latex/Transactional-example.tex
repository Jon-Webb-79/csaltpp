\doxysection{Transactional}
\hypertarget{Transactional-example}{}\label{Transactional-example}Save current arena state as a checkpoint.

Save current arena state as a checkpoint\begin{DoxyReturn}{Returns}
Opaque checkpoint pointer, or nullptr on failure
\end{DoxyReturn}
Creates a checkpoint of the current arena state. The checkpoint can later be used with restore() to rollback all allocations made after the checkpoint. This is useful for transactional or scoped allocations.

The checkpoint is allocated separately (not from the arena) and must be freed by restore(). If you don\textquotesingle{}t call restore(), you leak the checkpoint (but not the arena memory).

Returns nullptr if\+:
\begin{DoxyItemize}
\item Arena has no chunks
\item Checkpoint allocation fails
\end{DoxyItemize}

\begin{DoxyWarning}{Warning}
You must call restore() on the checkpoint to free it. Losing the checkpoint pointer without calling restore() causes a memory leak.
\end{DoxyWarning}
