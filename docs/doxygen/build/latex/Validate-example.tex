Checks if the given pointer points to memory within any of this arena\textquotesingle{}s chunks. This is useful for debugging and validation.

Returns false for\+:
\begin{DoxyItemize}
\item nullptr
\item Pointers allocated by other arenas
\item Pointers allocated by other allocators
\item Invalid pointers
\end{DoxyItemize}
