class cslt\+::\+AVLTree$<$ T, Compare $>$}
Allocator-\/backed generic AVL tree container. 

Provides a self-\/balancing binary search tree that stores values of type {\ttfamily T} inline within each node. The tree object itself, its primary slab of nodes, and any overflow nodes are all allocated through the supplied allocator.

Key features\+:
\begin{DoxyItemize}
\item Custom allocator support
\item AVL balancing with O(log n) insert / remove / find
\item Slab-\/backed primary node storage
\item Internal free-\/list reuse for removed nodes
\item Optional overflow allocation when the slab is exhausted
\item Comparator-\/driven ordering
\item Optional duplicate support
\item RAII cleanup through \doxylink{classcslt_1_1AVLTreeDeleter}{AVLTree\+Deleter}
\end{DoxyItemize}

Usage pattern\+:
\begin{DoxyItemize}
\item Must be initialised via the static factory function \doxylink{classcslt_1_1AVLTree_a193330d8fd7b75cb2f2cc76a3a48b33c}{init()}
\item Cannot be constructed directly (private constructor)
\item Cleaned up through \doxylink{classcslt_1_1AVLTreeDeleter}{AVLTree\+Deleter}
\end{DoxyItemize}
