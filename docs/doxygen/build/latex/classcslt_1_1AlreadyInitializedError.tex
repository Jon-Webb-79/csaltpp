\doxysubsection{Detailed Description}
Already initialized error. 

\mbox{\hyperlink{classcslt_1_1AlreadyInitializedError}{Already\+Initialized\+Error}} represents an error when attempting to initialize an object that has already been initialized (double-\/initialization).
