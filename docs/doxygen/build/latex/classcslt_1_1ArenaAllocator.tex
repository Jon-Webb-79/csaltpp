\doxysubsection{Detailed Description}
Fast, region-\/based memory allocator that allocates memory in chunks. 

\mbox{\hyperlink{classcslt_1_1ArenaAllocator}{Arena\+Allocator}} is a memory allocator that uses \char`\"{}arena\char`\"{} or \char`\"{}region\char`\"{} allocation strategy. It allocates memory sequentially from large chunks and does not support individual deallocation. All memory is freed together when the arena is reset or destroyed.

Key characteristics\+:
\begin{DoxyItemize}
\item Very fast allocation (just pointer bumping)
\item No per-\/allocation metadata overhead
\item No fragmentation
\item No individual deallocation (use \mbox{\hyperlink{classcslt_1_1ArenaAllocator_a33e3302b97aed2d9c6bd764ca028e191}{reset()}} instead)
\item Supports checkpoints for transactional rollback
\item Optional dynamic growth with additional chunks
\end{DoxyItemize}

Three initialization modes\+:
\begin{DoxyItemize}
\item \mbox{\hyperlink{classcslt_1_1ArenaAllocator_a322c802722e6491f4b1112d0893660a3}{Heap()}}\+: Dynamically allocated arena that owns its memory
\item \mbox{\hyperlink{classcslt_1_1ArenaAllocator_a6d245f99bc1ba17a2785f66c43a61e95}{Stack()}}\+: Arena using a user-\/provided buffer (doesn\textquotesingle{}t own memory)
\item \mbox{\hyperlink{classcslt_1_1ArenaAllocator_ae44d42c85dbd78b7a424e7a76c3fce32}{Sub\+Arena()}}\+: Arena allocated within a parent arena (doesn\textquotesingle{}t own memory) 
\end{DoxyItemize}\begin{Desc}

Performs a single allocation from {\ttfamily buddy} and constructs the \mbox{\hyperlink{classcslt_1_1ArenaAllocator}{Arena\+Allocator}} in-\/place at the returned base pointer. The arena is fixed-\/capacity\+:

\item Destruction returns the entire region back to the buddy allocator
