\doxysubsection{Detailed Description}
Argument and input validation errors. 

\mbox{\hyperlink{classcslt_1_1ArgumentError}{Argument\+Error}} represents errors related to invalid function arguments, null pointers, out-\/of-\/bounds access, and other input validation failures.
