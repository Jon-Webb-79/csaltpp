\doxysubsection{Detailed Description}
\subsubsection*{template$<$typename T$>$\newline
class cslt\+::\+Array$<$ T $>$}

Allocator-\/backed generic dynamic array container. 

Provides a resizable array container that uses custom allocators for memory management. Both the \mbox{\hyperlink{classcslt_1_1Array}{Array}} struct and its internal data buffer are allocated through the provided allocator.

Key features\+:
\begin{DoxyItemize}
\item Custom allocator support (heap, arena, buddy, slab, etc.)
\item Generic element type via template parameter
\item Tiered growth strategy to avoid runaway allocation at large sizes
\item Safe insertion and removal via push/pop family of methods
\item Bounds-\/checked read via \mbox{\hyperlink{classcslt_1_1Array_a01ca5eb33c0b1e4e46cc7379f872e6df}{operator\mbox{[}$\,$\mbox{]}(size\+\_\+t) const }}returning Expected$<$\+T$>$
\item Bounds-\/checked write via \mbox{\hyperlink{classcslt_1_1Array_a6a1cea7677e1cea74ed7fc3a5b8216c4}{set(size\+\_\+t, const T\&)}} returning Expected$<$bool$>$
\item Copy factory via \mbox{\hyperlink{classcslt_1_1Array_a01e0a4d91fda691cbe8f216ae74017c8}{copy()}}; move construction explicitly deleted
\item RAII-\/based memory management through init factory function
\end{DoxyItemize}

Growth tiers (in elements)\+:
\begin{DoxyItemize}
\item 0 -\/$>$ 1
\item $<$ 1024 -\/$>$ 2x
\item $<$ 8192 -\/$>$ 1.\+5x (cap + cap/2)
\item $<$ 65536 -\/$>$ 1.\+25x (cap + cap/4)
\item $>$= 65536 -\/$>$ cap + 256 (linear increment)
\end{DoxyItemize}

Shift strategy\+:
\begin{DoxyItemize}
\item Trivially copyable T\+: std\+::memmove (compiler-\/vectorisable)
\item Non-\/trivial T\+: placement-\/new / explicit destructor loop
\end{DoxyItemize}

Usage pattern\+:
\begin{DoxyItemize}
\item Must be initialised via the static factory function \mbox{\hyperlink{classcslt_1_1Array_ae39a55a8e6cff462c8ad9a4a1c6d06ef}{init()}}
\item Cannot be constructed directly (private constructor)
\item Automatically manages both the \mbox{\hyperlink{classcslt_1_1Array}{Array}} object and its buffer memory
\item Cleaned up through \mbox{\hyperlink{classcslt_1_1ArrayDeleter}{Array\+Deleter}}
\end{DoxyItemize}

Iterates over the populated elements of {\ttfamily other} and appends each one via \mbox{\hyperlink{classcslt_1_1Array_a726d2a2a623ba9b343d2188df90ef528}{push\+\_\+back()}}, which uses the tiered growth strategy as needed. If any individual \mbox{\hyperlink{classcslt_1_1Array_a726d2a2a623ba9b343d2188df90ef528}{push\+\_\+back()}} fails (reallocation error), the method returns false immediately; elements already appended before the failure remain in the array.

\begin{DoxyNote}{Note}
Self-\/concatenation (passing this array as {\ttfamily other}) is safe because \mbox{\hyperlink{classcslt_1_1Array_a726d2a2a623ba9b343d2188df90ef528}{push\+\_\+back()}} always reads from {\ttfamily other} before writing, and the snapshot of other.\+len\+\_\+ is taken once before the loop.
\end{DoxyNote}

Reverse the order of all elements in the array in place. 

For trivially copyable T the reversal is delegated to simd\+\_\+reverse\+\_\+uint8(), which is resolved at compile time to the best available SIMD back-\/end (AVX-\/512, AVX2, AVX, SSE4.\+1, SSSE3, SSE2, NEON, SVE, SVE2) or a portable scalar fallback. The function treats each element as an opaque bag of sizeof(\+T) bytes and swaps element positions — it does not reverse the bytes within an individual element.

For non-\/trivial T, a scalar swap loop is used that respects move construction and destruction semantics.

Arrays with fewer than two elements are left unchanged.
