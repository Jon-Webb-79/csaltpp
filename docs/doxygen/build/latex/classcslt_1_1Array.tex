\doxysubsection{Detailed Description}
\subsubsection*{template$<$\mbox{\hyperlink{classcslt_1_1Expected}{typename}} \mbox{\hyperlink{classcslt_1_1Expected}{T}}$>$\newline
class cslt\+::\+Array$<$ T $>$}
Allocator-\/backed generic dynamic array container. 

Provides a resizable array container that uses custom allocators for memory management. Both the \doxylink{classcslt_1_1Array}{Array} struct and its internal data buffer are allocated through the provided allocator.

Key features\+:
\begin{DoxyItemize}
\item Custom allocator support (heap, arena, buddy, slab, etc.)
\item Generic element type via template parameter
\item Tiered growth strategy to avoid runaway allocation at large sizes
\item Safe insertion and removal via push/pop family of methods
\item Bounds-\/checked read via \doxylink{classcslt_1_1Array_a595c212a003a5f7a072922aad43ed8d6}{operator\mbox{[}$\,$\mbox{]}(size\+\_\+t) const }returning Expected$<$\+T$>$
\item Bounds-\/checked write via \doxylink{classcslt_1_1Array_aa499cbbaf906d81a422d6fa37d22ca42}{set(size\+\_\+t, const T\&)} returning Expected$<$bool$>$
\item Copy factory via \doxylink{classcslt_1_1Array_a9b000e9e05baf459afc5e334a7130561}{copy()}; move construction explicitly deleted
\item RAII-\/based memory management through init factory function
\end{DoxyItemize}

Growth tiers (in elements)\+:
\begin{DoxyItemize}
\item 0 -\/\texorpdfstring{$>$}{>} 1
\item \texorpdfstring{$<$}{<} 1024 -\/\texorpdfstring{$>$}{>} 2x
\item \texorpdfstring{$<$}{<} 8192 -\/\texorpdfstring{$>$}{>} 1.\+5x (cap + cap/2)
\item \texorpdfstring{$<$}{<} 65536 -\/\texorpdfstring{$>$}{>} 1.\+25x (cap + cap/4)
\item \texorpdfstring{$>$}{>}= 65536 -\/\texorpdfstring{$>$}{>} cap + 256 (linear increment)
\end{DoxyItemize}

Reverse the order of all elements in the array in place. 

For trivially copyable T the reversal is delegated to simd\+\_\+reverse\+\_\+uint8(), which is resolved at compile time to the best available SIMD back-\/end (AVX-\/512, AVX2, AVX, SSE4.\+1, SSSE3, SSE2, NEON, SVE, SVE2) or a portable scalar fallback. The function treats each element as an opaque bag of sizeof(\+T) bytes and swaps element positions — it does not reverse the bytes within an individual element.

For non-\/trivial T, a scalar swap loop is used that respects move construction and destruction semantics.

Arrays with fewer than two elements are left unchanged.
