Custom deleter for \mbox{\hyperlink{classcslt_1_1Array}{Array}} instances. 

Implements proper cleanup for \mbox{\hyperlink{classcslt_1_1Array}{Array}} objects by\+:
\begin{DoxyEnumerate}
\item Calling the \mbox{\hyperlink{classcslt_1_1Array}{Array}} destructor (which destroys elements and frees the buffer)
\item Freeing the \mbox{\hyperlink{classcslt_1_1Array}{Array}} object itself Both operations use the allocator stored inside the \mbox{\hyperlink{classcslt_1_1Array}{Array}}.
\end{DoxyEnumerate}

This deleter is intended for use with \mbox{\hyperlink{classcslt_1_1UniquePtr}{Unique\+Ptr}} to provide RAII semantics.
