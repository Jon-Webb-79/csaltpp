\subsubsection*{template$<$\mbox{\hyperlink{classcslt_1_1Expected}{typename}} \mbox{\hyperlink{classcslt_1_1Expected}{K}}, \mbox{\hyperlink{classcslt_1_1Expected}{typename}} \mbox{\hyperlink{classcslt_1_1Expected}{V}}$>$\newline
class cslt\+::\+Dict$<$ K, V $>$}
Allocator-\/backed generic hash dictionary mapping keys of type K to values of type V. 

Implements a chained hash table using the Murmur\+Hash3-\/inspired hash function from the companion C implementation. Both the \doxylink{classcslt_1_1Dict}{Dict} object and every internal node are allocated through the provided \doxylink{classcslt_1_1Allocator}{Allocator}, enabling deterministic memory behaviour across heap, arena, buddy, and slab allocators.

Key features\+:
\begin{DoxyItemize}
\item Template parameters K and V decouple key and value types completely
\item K must be trivially copyable; keys are hashed over their raw bytes
\item Key equality uses operator== when available, memcmp as fallback
\item V may be any copy-\/constructible, destructible type
\item Optional automatic growth when load factor exceeds 0.\+75
\item Factory pattern via \doxylink{classcslt_1_1Dict_a49eea3f6e2ef88c80a1003042c38b7cb}{init()} prevents uninitialised instances
\item RAII cleanup through \doxylink{classcslt_1_1DictDeleter}{Dict\+Deleter} and \doxylink{classcslt_1_1UniquePtr}{Unique\+Ptr}
\item \doxylink{classcslt_1_1Dict_af9e30eb9070fc744e73c6ed0995fd21c}{foreach()} iteration accepts any callable (lambda, functor, function pointer)
\end{DoxyItemize}
