\doxysubsection{Detailed Description}
Mathematical domain error. 

\mbox{\hyperlink{classcslt_1_1DomainError}{Domain\+Error}} represents an error when an input value is outside the valid domain for a mathematical function (e.\+g., negative input to square root, log of negative number).
