\doxysubsection{Detailed Description}
Base class for all cslt library exceptions with fixed-\/size error messages. 

The \doxylink{classcslt_1_1Error}{Error} class provides a lightweight, STL-\/independent exception mechanism with predictable memory usage. \doxylink{classcslt_1_1Error}{Error} messages are stored in a fixed-\/size buffer to avoid heap allocations, making it suitable for embedded systems and real-\/time applications.

All error messages are capped at MAX\+\_\+\+MESSAGE\+\_\+\+LEN (256 characters). Messages exceeding this length are silently truncated.
