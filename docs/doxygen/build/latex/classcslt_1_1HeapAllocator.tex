\doxysubsection{Detailed Description}
\doxylink{classcslt_1_1Allocator}{Allocator} wrapper around system heap (operator new/delete) 

\doxylink{classcslt_1_1HeapAllocator}{Heap\+Allocator} is a simple wrapper around the system\textquotesingle{}s dynamic memory allocation facilities (operator new, operator delete, and platform-\/specific aligned allocation functions). It does not own or track memory -\/ all allocations go directly to the OS heap.

Key characteristics\+:
\begin{DoxyItemize}
\item Does not own memory (\doxylink{classcslt_1_1Allocator_a5eed4e825db775062f2a8d72b0a80185}{owns\+\_\+memory()} returns false)
\item Does not track allocations (\doxylink{classcslt_1_1Allocator_a4ebb5393b6462a066d6a8f8fbd1c6f37}{size()} returns 0)
\item No fixed capacity (\doxylink{classcslt_1_1Allocator_a91c8438280ddbe1fa7ecaf8cc555daaf}{total\+\_\+alloc()} and \doxylink{classcslt_1_1Allocator_ac5a7770e8ed38355d7ae996b3475a4c5}{allocated()} return 0)
\item Uses DYNAMIC memory type
\item Thread-\/safety depends on system allocator
\item No overhead beyond system allocator overhead
\end{DoxyItemize}

Use this allocator when\+:
\begin{DoxyItemize}
\item You need a uniform interface with other allocators
\item You want to switch between allocator types at runtime
\item You need alignment support beyond standard new
\item You don\textquotesingle{}t need memory tracking or limits
\end{DoxyItemize}

Alignment behavior\+:
\begin{DoxyItemize}
\item For alignments \texorpdfstring{$<$}{<}= max\+\_\+align\+\_\+t\+: uses operator new
\item For alignments \texorpdfstring{$>$}{>} max\+\_\+align\+\_\+t\+: uses platform-\/specific functions (posix\+\_\+memalign on POSIX, \+\_\+aligned\+\_\+malloc on Windows)
\end{DoxyItemize}
