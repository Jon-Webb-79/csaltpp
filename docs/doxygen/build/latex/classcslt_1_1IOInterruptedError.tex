\doxysubsection{Detailed Description}
I/O operation interrupted error. 

\mbox{\hyperlink{classcslt_1_1IOInterruptedError}{IOInterrupted\+Error}} represents an error when an I/O operation is interrupted (e.\+g., by a signal like EINTR).
