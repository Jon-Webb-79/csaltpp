\doxysubsection{Detailed Description}
Non-\/blocking operation would block error. 

\mbox{\hyperlink{classcslt_1_1IOWouldBlockError}{IOWould\+Block\+Error}} represents an error when a non-\/blocking I/O operation would block (EWOULDBLOCK/\+EAGAIN).
