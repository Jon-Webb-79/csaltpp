\doxysubsection{Detailed Description}
Mathematical and numerical computation errors. 

\mbox{\hyperlink{classcslt_1_1MathError}{Math\+Error}} represents errors related to mathematical operations such as division by zero, matrix singularities, numeric overflow, and domain errors.
