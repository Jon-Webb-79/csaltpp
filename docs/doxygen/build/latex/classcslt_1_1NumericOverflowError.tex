\doxysubsection{Detailed Description}
Numeric overflow or underflow error. 

\mbox{\hyperlink{classcslt_1_1NumericOverflowError}{Numeric\+Overflow\+Error}} represents an error when a numeric computation results in overflow (exceeds maximum) or underflow (below minimum representable value).
