\doxysubsection{Detailed Description}
System out of memory error. 

\mbox{\hyperlink{classcslt_1_1OutOfMemoryError}{Out\+Of\+Memory\+Error}} represents an error when the system is completely out of memory or an allocator has reached its limit.
