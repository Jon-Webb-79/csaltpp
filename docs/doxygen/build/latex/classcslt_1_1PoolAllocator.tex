\doxysubsection{Detailed Description}
Fixed-\/size block allocator with O(1) allocation and deallocation. 

\mbox{\hyperlink{classcslt_1_1PoolAllocator}{Pool\+Allocator}} manages memory as a collection of uniformly-\/sized blocks, providing constant-\/time allocation and deallocation through free-\/list recycling. All allocations return blocks of exactly the same size, making it ideal for object pools and frequently allocated/deallocated data structures.

The pool carves blocks from contiguous memory slices backed by an arena. Freed blocks are returned to a linked free-\/list for O(1) reuse. Optionally, the pool can request additional slices when capacity is exhausted.
