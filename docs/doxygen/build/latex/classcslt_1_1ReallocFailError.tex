\doxysubsection{Detailed Description}
Memory reallocation failure error. 

\mbox{\hyperlink{classcslt_1_1ReallocFailError}{Realloc\+Fail\+Error}} represents an error when realloc fails to resize a memory block (the original buffer remains unchanged).
