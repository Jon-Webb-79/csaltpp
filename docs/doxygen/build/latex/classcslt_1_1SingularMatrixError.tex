\doxysubsection{Detailed Description}
Singular or non-\/invertible matrix error. 

\mbox{\hyperlink{classcslt_1_1SingularMatrixError}{Singular\+Matrix\+Error}} represents an error when attempting operations that require a non-\/singular matrix (e.\+g., matrix inversion, solving linear systems) but the matrix is singular.
