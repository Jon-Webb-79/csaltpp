\doxysubsection{Detailed Description}
Fixed-\/size object allocator using slab allocation with buddy backing. 

\doxylink{classcslt_1_1SlabAllocator}{Slab\+Allocator} provides O(1) allocation and deallocation for fixed-\/size objects by pre-\/carving memory pages (slabs) into equally-\/sized slots. All slots within a slab have identical size and alignment, making it ideal for allocating many instances of the same type. This allocator is implemented on the heap. In order to drive compliance with MISRA standards, this class can be ommitted from compilation with the {\ttfamily STATIC ONLY} flag.

\begin{DoxyNote}{Note}
This class is conditionally compiled. If STATIC\+\_\+\+ONLY is defined, \doxylink{classcslt_1_1SlabAllocator}{Slab\+Allocator} will not be available.
\end{DoxyNote}
{\bfseries{Key Features\+:}}
\begin{DoxyItemize}
\item O(1) allocation and deallocation (pop/push from free list)
\item Zero fragmentation (all objects same size)
\item Configurable alignment support
\item Lazy page allocation (grows on demand)
\item Backed by \doxylink{classcslt_1_1BuddyAllocator}{Buddy\+Allocator} for page management
\end{DoxyItemize}

{\bfseries{Limitations\+:}}
\begin{DoxyItemize}
\item Only supports single fixed size per allocator instance
\item Cannot resize objects (realloc only works for same size)
\item Not thread-\/safe
\item Slab must be destroyed before backing buddy allocator
\end{DoxyItemize}

{\bfseries{Use Cases\+:}}
\begin{DoxyItemize}
\item Allocating many instances of the same struct/class
\item Object pools (e.\+g., particle systems, network packets)
\item Cache-\/friendly data structures (same-\/sized objects)
\item Reducing fragmentation for uniform allocations
\end{DoxyItemize}

Destructor -\/ Frees all slab pages back to buddy allocator. 

Walks the linked list of allocated pages and returns each page to the backing buddy allocator. The \doxylink{classcslt_1_1SlabAllocator}{Slab\+Allocator} structure itself is also freed back to buddy via \doxylink{structcslt_1_1SlabDeleter}{Slab\+Deleter}.

All outstanding allocations become invalid after destruction.

\begin{DoxyNote}{Note}
This destructor is called automatically by \doxylink{structcslt_1_1SlabDeleter}{Slab\+Deleter} when the \doxylink{classcslt_1_1UniquePtr}{Unique\+Ptr} goes out of scope or is reset.

The backing \doxylink{classcslt_1_1BuddyAllocator}{Buddy\+Allocator} must still be alive when this destructor runs. Always ensure slabs are destroyed before their buddy allocator.
\end{DoxyNote}
\begin{DoxyWarning}{Warning}
All pointers obtained from this slab become invalid. Accessing them after destruction results in undefined behavior.
\end{DoxyWarning}

Allocate a fixed-\/size object from the slab. 


\begin{DoxyParams}{Parameters}

\hline
{\em zeroed} & If true, zero-\/initialize the allocated memory\\

\end{DoxyParams}
\begin{DoxyReturn}{Returns}
\doxylink{classcslt_1_1Expected}{Expected} containing pointer to allocated memory on success, or error on failure
\end{DoxyReturn}
Allocates a fixed-\/size object by popping a slot from the free list. If the free list is empty, a new page is allocated from the backing buddy allocator (lazy growth).

{\bfseries{Allocation Process\+:}}
\begin{DoxyEnumerate}
\item Validate bytes == obj\+\_\+size (strict size requirement)
\item If free\+\_\+list empty, call grow\+\_\+() to allocate a new page
\item Pop first slot from free\+\_\+list (O(1) operation)
\item Optionally zero-\/initialize the memory
\item Update accounting (in\+\_\+use\+\_\+blocks, size)
\end{DoxyEnumerate}

{\bfseries{Performance\+:}}
\begin{DoxyItemize}
\item O(1) when free slots available (simple pointer pop)
\item O(log n) when growing (buddy allocator overhead for new page)
\item Average case\+: O(1) amortized over many allocations
\end{DoxyItemize}

{\bfseries{Size Constraint\+:}} Unlike general-\/purpose allocators, slab allocators only support ONE fixed size. The bytes parameter MUST exactly match the obj\+\_\+size specified during \doxylink{classcslt_1_1SlabAllocator_a6a681790bea29900146bdaec1a233aab}{With\+Buddy()} creation.

{\bfseries{Alignment\+:}} All slots are pre-\/aligned to the alignment specified at creation. This method does NOT guarantee specific alignment beyond that -\/ use \doxylink{classcslt_1_1SlabAllocator_a54b386924cb58c7d9bbd7b5fcc4647f3}{alloc\+\_\+aligned()} if you need to verify alignment requirements.

\begin{DoxyNote}{Note}
bytes must EXACTLY equal obj\+\_\+size. Requesting any other size results in an \doxylink{classcslt_1_1ArgumentError}{Argument\+Error}.

The first allocation from a newly created slab triggers page allocation from the buddy allocator (lazy initialization).

Returned pointers remain valid until freed with \doxylink{classcslt_1_1SlabAllocator_a5428a1eeb7110ad52a5c69ae1e79057d}{return\+\_\+element()} or until the slab is \doxylink{classcslt_1_1SlabAllocator_a1da4e13544b8c601bb44ecd65de9ea1c}{reset()} or destroyed.
\end{DoxyNote}

Allocates a fixed-\/size object from the slab with explicit alignment verification. The slab pre-\/aligns all slots during page creation, so this method validates that the requested alignment is satisfied by the slab\textquotesingle{}s alignment.

{\bfseries{Allocation Process\+:}}
\begin{DoxyEnumerate}
\item Validate bytes == obj\+\_\+size (strict size requirement)
\item Normalize alignment (0 → max\+\_\+align\+\_\+t, round to power of 2)
\item Verify requested\+\_\+align \texorpdfstring{$<$}{<}= slab\textquotesingle{}s align (pre-\/aligned slots)
\item Delegate to \doxylink{classcslt_1_1SlabAllocator_ae82a6b86f5ce311987d82120338b5249}{alloc()} to pop from free list
\item All returned pointers are guaranteed aligned
\end{DoxyEnumerate}

{\bfseries{Alignment Constraint\+:}} The requested alignment CANNOT exceed the slab\textquotesingle{}s alignment specified at creation. To allocate with higher alignment, create the slab with a larger alignment value in \doxylink{classcslt_1_1SlabAllocator_a6a681790bea29900146bdaec1a233aab}{With\+Buddy()}.

{\bfseries{Performance\+:}} Same as \doxylink{classcslt_1_1SlabAllocator_ae82a6b86f5ce311987d82120338b5249}{alloc()} -\/ O(1) amortized. The alignment check is just a comparison, adding negligible overhead.

\begin{DoxyNote}{Note}
Requested alignment must be \texorpdfstring{$<$}{<}= slab\textquotesingle{}s alignment. If you need higher alignment, create a new slab with \doxylink{classcslt_1_1SlabAllocator_a6a681790bea29900146bdaec1a233aab}{With\+Buddy()} using the desired alignment.

All slots in the slab are pre-\/aligned, so this method just validates the requirement is met -\/ it doesn\textquotesingle{}t perform additional alignment.

alignment is normalized to a power of 2. Requesting 48 will be rounded to 64 before checking against slab alignment.
\end{DoxyNote}

\begin{DoxyReturn}{Returns}

\end{DoxyReturn}
Returns the count of slots currently in use, calculated from the tracked byte usage divided by object size.

Check if pointer is a valid allocation from this slab. 


\begin{DoxyParams}{Parameters}
{\em ptr} & Pointer to validate\\
\hline
\end{DoxyParams}
\begin{DoxyReturn}{Returns}
true if ptr is a valid slot from this slab, false otherwise
\end{DoxyReturn}
Validates whether a pointer points to a valid slot in this slab allocator by checking if it belongs to one of the slab\textquotesingle{}s pages and is properly aligned to a slot boundary.

{\bfseries{Validation Checks\+:}}
\begin{DoxyEnumerate}
\item Pointer is not null
\item Pointer belongs to one of this slab\textquotesingle{}s pages
\item Pointer is not in the page header region
\item Pointer is aligned on slot boundary (offset \% slot\+\_\+size == 0)
\end{DoxyEnumerate}

{\bfseries{Limitations\+:}}
\begin{DoxyItemize}
\item Cannot detect use-\/after-\/free (freed pointer still validates)
\item Cannot detect double-\/free
\item Cannot detect never-\/allocated slots
\item Only checks structural validity, not allocation state
\end{DoxyItemize}

\begin{DoxyNote}{Note}
This is a structural check only. A freed pointer will still return true if it\textquotesingle{}s a valid slot location.

Performance is O(pages) due to page lookup.
\end{DoxyNote}

Slab allocators only support fixed-\/size objects, so realloc has very limited functionality compared to general-\/purpose allocators. The only supported operation is "{}realloc to same size"{} which simply returns the same pointer.

{\bfseries{Special Cases\+:}}
\begin{DoxyItemize}
\item realloc(nullptr, 0, n) → Equivalent to alloc(n)
\item realloc(ptr, old, 0) → Frees ptr, returns nullptr (success)
\item realloc(ptr, old, new) where old == new == obj\+\_\+size → Returns same ptr
\item realloc(ptr, old, new) where old != new → ERROR (cannot resize)
\end{DoxyItemize}

{\bfseries{Why No Resize Support\+:}} Slab allocators pre-\/carve memory into fixed-\/size slots. There is no concept of "{}growing"{} or "{}shrinking"{} an object. All slots are identical. To change object size, you must free the old object and allocate from a different slab with the desired size.

{\bfseries{Same Size Behavior\+:}} When old\+\_\+bytes == new\+\_\+bytes == obj\+\_\+size, returns the same pointer with no reallocation. This is an O(1) no-\/op.

\begin{DoxyNote}{Note}
Slab allocators CANNOT resize objects. Both old\+\_\+bytes and new\+\_\+bytes must equal obj\+\_\+size for the operation to succeed.

To "{}resize"{} an object, you must\+: (1) Allocate from a slab with the new size, (2) Copy data, (3) Free the old object.

The zeroed parameter has no effect when old\+\_\+bytes == new\+\_\+bytes since no new space is allocated.
\end{DoxyNote}

Realloc with alignment for slab allocator (limited -\/ same size only)

\begin{DoxyReturn}{Returns}

Similar to \doxylink{classcslt_1_1SlabAllocator_a151b449da25dab69e033036dd27255db}{realloc()}, but with alignment verification. Slab allocators only support fixed-\/size objects, so this can only "{}realloc"{} to the same size while verifying alignment requirements.

{\bfseries{Special Cases\+:}}
\begin{DoxyItemize}
\item realloc\+\_\+aligned(nullptr, 0, n, a) → Equivalent to alloc\+\_\+aligned(n, a)
\item realloc\+\_\+aligned(ptr, old, 0, a) → Frees ptr, returns nullptr (success)
\item realloc\+\_\+aligned(ptr, old, new, a) where old == new == obj\+\_\+size → Same ptr
\item realloc\+\_\+aligned(ptr, old, new, a) where old != new → ERROR (cannot resize)
\item realloc\+\_\+aligned(ptr, old, old, a) where a \texorpdfstring{$>$}{>} slab\+\_\+align → ERROR
\end{DoxyItemize}

{\bfseries{Alignment Verification\+:}} The requested alignment must not exceed the slab\textquotesingle{}s alignment. If the pointer already satisfies the alignment (which it should, since all slots are pre-\/aligned), the same pointer is returned.

{\bfseries{Same Size Behavior\+:}} When old\+\_\+bytes == new\+\_\+bytes == obj\+\_\+size and alignment is satisfied, returns the same pointer with no reallocation (O(1) no-\/op).

\begin{DoxyNote}{Note}
Slab allocators CANNOT resize objects. Both old\+\_\+bytes and new\+\_\+bytes must equal obj\+\_\+size.

Requested alignment must not exceed the slab\textquotesingle{}s alignment specified at creation.

All slots are pre-\/aligned, so this method just validates the requirement is met -\/ it doesn\textquotesingle{}t perform additional alignment.

Changing alignment requirements cannot be satisfied if new alignment exceeds slab alignment. Create object in slab with appropriate alignment instead.
\end{DoxyNote}

Get remaining capacity in bytes. 

\begin{DoxyReturn}{Returns}
Number of bytes available for allocation
\end{DoxyReturn}
Returns the total available capacity (allocated pages) minus bytes currently in use. This represents how much can be allocated before needing to grow a new page.

Calculated as\+: (total\+\_\+blocks × obj\+\_\+size) -\/ \doxylink{classcslt_1_1Allocator_a4ebb5393b6462a066d6a8f8fbd1c6f37}{size()}

\begin{DoxyNote}{Note}
This is capacity in allocated pages, not total memory available from the buddy allocator. Slab may grow beyond this.
\end{DoxyNote}

{\footnotesize\ttfamily \mbox{\hyperlink{classcslt_1_1Expected}{bool}} cslt\+::\+Slab\+Allocator\+::reset (\begin{DoxyParamCaption}\item[{\mbox{\hyperlink{classcslt_1_1Expected}{bool}}}]{trim = {\ttfamily \mbox{\hyperlink{classcslt_1_1Expected}{false}}} }\end{DoxyParamCaption})\hspace{0.3cm}{\ttfamily [override]}, {\ttfamily [virtual]}}



Bulk free all allocations and rebuild free list. 


\begin{DoxyParams}{Parameters}
{\em trim} & Ignored (present for interface compatibility -\/ slabs don\textquotesingle{}t trim)\\
\hline
\end{DoxyParams}
\begin{DoxyReturn}{Returns}
true if reset successful, false on error
\end{DoxyReturn}
Performs a bulk deallocation of all objects by clearing accounting and rebuilding the free list from scratch. All outstanding allocations become invalid. Pages remain allocated (not returned to buddy).

{\bfseries{Reset Process\+:}}
\begin{DoxyEnumerate}
\item Validate slab geometry (sanity check)
\item Clear accounting (len\+\_\+bytes = 0, size = 0)
\item Clear free list (free\+\_\+list = nullptr)
\item Walk all pages and re-\/carve slots
\item Rebuild free list with all slots
\end{DoxyEnumerate}

{\bfseries{Performance\+:}} O(pages × objects\+\_\+per\+\_\+page) -\/ must walk every slot to rebuild list. Much faster than individual frees when deallocating many objects.

{\bfseries{Pages Not Freed\+:}} Unlike trim operations in other allocators, \doxylink{classcslt_1_1SlabAllocator_a1da4e13544b8c601bb44ecd65de9ea1c}{reset()} keeps all pages. The slab maintains its current capacity. Pages are only freed when the slab is destroyed.

{\bfseries{Use Cases\+:}}
\begin{DoxyItemize}
\item Per-\/frame allocations (game engines)
\item Request/response cycles (servers)
\item Test cleanup between test cases
\item Temporary scratch space that\textquotesingle{}s bulk-\/cleared
\end{DoxyItemize}

\begin{DoxyNote}{Note}
The trim parameter is IGNORED. Slab allocators never trim pages back to the buddy allocator. Pages persist until slab destruction.

After \doxylink{classcslt_1_1SlabAllocator_a1da4e13544b8c601bb44ecd65de9ea1c}{reset()}, ALL pointers obtained from this slab become invalid. Accessing them results in undefined behavior.

\doxylink{classcslt_1_1SlabAllocator_a1da4e13544b8c601bb44ecd65de9ea1c}{reset()} is significantly faster than calling \doxylink{classcslt_1_1SlabAllocator_a5428a1eeb7110ad52a5c69ae1e79057d}{return\+\_\+element()} on each allocation individually when you need to free everything.

The slab retains its full capacity. Subsequent allocations will reuse the existing pages without needing to grow.
\end{DoxyNote}
\begin{DoxyWarning}{Warning}
All outstanding allocations become invalid. Do not use any pointers obtained before \doxylink{classcslt_1_1SlabAllocator_a1da4e13544b8c601bb44ecd65de9ea1c}{reset()} after calling this function.
\end{DoxyWarning}

\doxylink{classcslt_1_1SlabAllocator}{Slab\+Allocator} does not support checkpoint/restore functionality. This method exists only for base class interface compatibility and always returns false.

{\bfseries{Why Not Supported\+:}} Since \doxylink{classcslt_1_1SlabAllocator_ac38d2e5e8062fc465c7beef3054a5572}{save()} always returns nullptr, there is no valid checkpoint to restore. The intrusive free list structure makes meaningful checkpointing impractical for slab allocators.

{\bfseries{Behavior\+:}} This method does nothing and always returns false, regardless of the checkpoint parameter value. The slab state is unchanged.

\begin{DoxyNote}{Note}
This method always returns false. It exists only to satisfy the base \doxylink{classcslt_1_1Allocator}{Allocator} interface.

The checkpoint parameter is completely ignored. Any value (including nullptr) will result in the same behavior\+: no-\/op and return false.

Calling this method has no side effects. The slab state is unchanged.
\end{DoxyNote}

Free an object back to the slab allocator. 


\begin{DoxyParams}{Parameters}
{\em ptr} & Pointer to free (returned from alloc, alloc\+\_\+aligned, realloc, or realloc\+\_\+aligned) \\
\hline
{\em bytes} & Ignored (present for interface compatibility) \\
\hline
{\em alignment} & Ignored (present for interface compatibility)\\
\hline
\end{DoxyParams}
Frees a previously allocated object by returning it to the free list. The freed slot becomes immediately available for subsequent allocations.

{\bfseries{Deallocation Process\+:}}
\begin{DoxyEnumerate}
\item Validate pointer is not null (null is silently ignored)
\item Find which page contains the pointer (walk pages list)
\item Verify pointer is within slots region (not in page header)
\item Verify pointer is aligned on slot boundary
\item Cast pointer to Slot and push onto free list
\item Update accounting (decrease in\+\_\+use\+\_\+blocks, size)
\end{DoxyEnumerate}

{\bfseries{Performance\+:}} O(p) where p is the number of pages (for page lookup), then O(1) to push onto free list. Typically O(1) amortized since most slabs have few pages.

{\bfseries{No Coalescing\+:}} Unlike \doxylink{classcslt_1_1BuddyAllocator}{Buddy\+Allocator}, slabs don\textquotesingle{}t coalesce. Freed slots simply go back on the free list and can be immediately reused. Pages remain allocated until the slab is destroyed.

\begin{DoxyNote}{Note}
The bytes and alignment parameters are IGNORED by \doxylink{classcslt_1_1SlabAllocator}{Slab\+Allocator}. They exist only for base class interface compatibility. The slab knows the object size from its configuration.

Passing nullptr is safe and does nothing (similar to free(nullptr)).

Invalid pointers are handled silently -\/ the function returns without error if the pointer is not from this slab, is misaligned, or is in the header region.

Double-\/free results in undefined behavior. The allocator cannot detect all double-\/free scenarios.

After this call, ptr becomes invalid. Accessing it results in undefined behavior.
\end{DoxyNote}
\begin{DoxyWarning}{Warning}
Do not free pointers from a different \doxylink{classcslt_1_1SlabAllocator}{Slab\+Allocator} instance. Each slab manages its own distinct set of pages.
\end{DoxyWarning}

Save allocator state (not supported) 

\begin{DoxyReturn}{Returns}
Always returns nullptr
\end{DoxyReturn}
\doxylink{classcslt_1_1SlabAllocator}{Slab\+Allocator} does not support checkpoint/restore functionality. This method exists only for base class interface compatibility and always returns nullptr.

{\bfseries{Why Not Supported\+:}} Slab allocators manage intrusive free lists with pointers embedded in freed slots. These pointers cannot be meaningfully saved and restored without complex serialization. Additionally, slabs are typically used for short-\/lived allocations where checkpointing doesn\textquotesingle{}t provide value.

{\bfseries{Alternatives\+:}}
\begin{DoxyItemize}
\item Use \doxylink{classcslt_1_1SlabAllocator_a1da4e13544b8c601bb44ecd65de9ea1c}{reset()} for bulk deallocation instead of \doxylink{classcslt_1_1SlabAllocator_a8be2184622f6278b44b1ad64a095014a}{restore()}
\item Manually track allocations if you need to revert state
\item Use \doxylink{classcslt_1_1BuddyAllocator}{Buddy\+Allocator} if you need checkpoint support
\end{DoxyItemize}

\begin{DoxyNote}{Note}
This method always returns nullptr. It exists only to satisfy the base \doxylink{classcslt_1_1Allocator}{Allocator} interface.

Calling this method has no side effects. The slab state is unchanged.

Do not attempt to pass the return value to \doxylink{classcslt_1_1SlabAllocator_a8be2184622f6278b44b1ad64a095014a}{restore()}. It will always be nullptr and \doxylink{classcslt_1_1SlabAllocator_a8be2184622f6278b44b1ad64a095014a}{restore()} will always fail.
\end{DoxyNote}

Generates a comprehensive human-\/readable report of the slab allocator\textquotesingle{}s current state, including geometry, capacity, usage, and per-\/page details.

{\bfseries{Report Contents\+:}}
\begin{DoxyItemize}
\item Object size and slot stride
\item Alignment requirements
\item Page size and header overhead
\item Number of pages and blocks per page
\item Total capacity and current usage (bytes and blocks)
\item Free block count (both geometric and from free list)
\item Utilization percentage
\item Per-\/page listing
\end{DoxyItemize}

{\bfseries{Cross-\/\+Validation\+:}} The report includes free block count calculated two ways\+:
\begin{DoxyItemize}
\item Geometric\+: total\+\_\+blocks -\/ in\+\_\+use\+\_\+blocks
\item Free list\+: Count by walking free list These should always match. Discrepancy indicates corruption.
\end{DoxyItemize}

{\bfseries{Buffer Size\+:}} Typical reports are 500-\/1000 bytes. Recommend 2KB-\/4\+KB buffer to accommodate slabs with many pages. If buffer is too small, the function returns false.

\begin{DoxyNote}{Note}
This is a diagnostic tool for debugging and monitoring. It\textquotesingle{}s not intended for production hot paths due to formatting overhead.

The report is human-\/readable, not machine-\/parseable. Don\textquotesingle{}t rely on exact format -\/ use the query methods (\doxylink{classcslt_1_1SlabAllocator_a57709b8ad1a9f7b4c2d0df1943800e96}{total\+\_\+blocks()}, \doxylink{classcslt_1_1Allocator_a4ebb5393b6462a066d6a8f8fbd1c6f37}{size()}, etc.) for programmatic access.

Factory method to create a slab allocator backed by a buddy allocator. 


\begin{DoxyParams}{Parameters}
{\em buddy} & Reference to backing \doxylink{classcslt_1_1BuddyAllocator}{Buddy\+Allocator} (non-\/owning, must outlive slab) \\
\hline
{\em obj\+\_\+size} & Size of each object in bytes (fixed for lifetime of slab) \\
\hline
{\em align} & Slot alignment in bytes (0 = alignof(max\+\_\+align\+\_\+t), rounded to power of 2) \\
\hline
{\em slab\+\_\+bytes\+\_\+hint} & Suggested page size in bytes (0 = automatic\+: 4KB or 64 objects)\\
\hline
\end{DoxyParams}
\begin{DoxyReturn}{Returns}
\doxylink{classcslt_1_1Expected}{Expected} containing \doxylink{classcslt_1_1UniquePtr}{Unique\+Ptr} to \doxylink{classcslt_1_1SlabAllocator}{Slab\+Allocator} on success, or error on failure
\end{DoxyReturn}
Creates a slab allocator that carves fixed-\/size objects from pages allocated from the buddy allocator. The allocator grows lazily -\/ pages are only allocated when the free list is exhausted.

{\bfseries{Initialization Process\+:}}
\begin{DoxyEnumerate}
\item Validate and normalize parameters (obj\+\_\+size \texorpdfstring{$>$}{>} 0, align to power of 2)
\item Allocate \doxylink{classcslt_1_1SlabAllocator}{Slab\+Allocator} structure from buddy
\item Calculate slot size (max of obj\+\_\+size and free list pointer size, aligned)
\item Calculate page geometry (header size, objects per page)
\item Return empty slab (no pages allocated yet -\/ lazy allocation)
\end{DoxyEnumerate}

{\bfseries{Parameter Normalization\+:}}
\begin{DoxyItemize}
\item align=0 → alignof(max\+\_\+align\+\_\+t) (typically 16 bytes)
\item align=non-\/pow2 → rounded up to next power of 2 (e.\+g., 48 → 64)
\item slab\+\_\+bytes\+\_\+hint=0 → max(4096, obj\+\_\+size \texorpdfstring{$\ast$}{*} 64 + page\+\_\+header)
\item Slot size adjusted to hold both object and free list linkage
\end{DoxyItemize}

{\bfseries{Page Size Calculation\+:}} When slab\+\_\+bytes\+\_\+hint=0, the default is the larger of\+:
\begin{DoxyItemize}
\item 4096 bytes (1 page)
\item Enough space for 64 objects plus page header
\end{DoxyItemize}

The final page size is adjusted so slots fit evenly with no tail waste.

{\bfseries{Lazy Allocation\+:}} No pages are allocated during initialization. The first call to \doxylink{classcslt_1_1SlabAllocator_ae82a6b86f5ce311987d82120338b5249}{alloc()} will trigger page allocation via grow\+\_\+().

\begin{DoxyNote}{Note}
The buddy allocator must outlive the slab allocator. The slab stores a non-\/owning pointer to buddy and will return pages to it during destruction.

obj\+\_\+size cannot be changed after creation. To allocate different sizes, create separate slab allocators.

The \doxylink{classcslt_1_1SlabAllocator}{Slab\+Allocator} structure itself is allocated from the buddy allocator, not from the system heap.
\end{DoxyNote}
