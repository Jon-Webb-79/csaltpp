\doxysubsection{Detailed Description}
Allocator-\/backed string container. 

Provides a string container that uses custom allocators for memory management. The string and its internal buffer are both allocated through the provided allocator.

Key features\+:
\begin{DoxyItemize}
\item Custom allocator support (heap, arena, buddy, slab, etc.)
\item Null-\/terminated C-\/string compatibility
\item Capacity management with optional pre-\/allocation
\item Safe truncation when capacity is insufficient
\item RAII-\/based memory management through init factory functions
\end{DoxyItemize}

Usage pattern\+:
\begin{DoxyItemize}
\item Must be initialized via static factory function \mbox{\hyperlink{classcslt_1_1String_ab1efd0bf9fe05c2af789e5fb74f7223c}{init()}}
\item Cannot be constructed directly (private constructor)
\item Automatically manages both string object and buffer memory
\item Cleaned up through custom deleter
\end{DoxyItemize}

\begin{DoxyParams}{Parameters}

\end{DoxyParams}
\begin{DoxyReturn}{Returns}
int8\+\_\+t comparison result\+:
\begin{DoxyItemize}
\item -\/1 if this string is less than str
\item 0 if strings are equal
\item 1 if this string is greater than str
\item -\/128 if either string is null (error sentinel)

Performs lexicographic comparison using unsigned byte values. The comparison follows standard strcmp semantics but returns a compact int8\+\_\+t result with three possible values plus an error sentinel.
\end{DoxyItemize}
\end{DoxyReturn}
Comparison semantics\+:
\begin{DoxyItemize}
\item Characters are compared as unsigned bytes (0-\/255)
\item Comparison proceeds left-\/to-\/right until a difference is found
\item If one string is a prefix of the other, the shorter is considered less
\item Null terminators are considered for the C-\/string parameter
\item The \mbox{\hyperlink{classcslt_1_1String}{String}}\textquotesingle{}s logical length (len\+\_\+) determines comparison extent
\end{DoxyItemize}

Return value interpretation\+:
\begin{DoxyItemize}
\item -\/1\+: This string sorts before str (this $<$ str)
\item 0\+: Strings are identical in content and length
\item 1\+: This string sorts after str (this $>$ str)
\item -\/128\+: \mbox{\hyperlink{classcslt_1_1Error}{Error}} condition (null pointer detected)
\end{DoxyItemize}

\begin{DoxyParagraph}{Edge cases\+:}

\begin{DoxyItemize}
\item Empty strings\+: Compare as equal if both are empty
\item Embedded nulls in \mbox{\hyperlink{classcslt_1_1String}{String}}\+: Comparison stops at logical length, not null
\item C-\/string shorter than \mbox{\hyperlink{classcslt_1_1String}{String}}\+: C-\/string is considered less
\item C-\/string longer than \mbox{\hyperlink{classcslt_1_1String}{String}}\+: \mbox{\hyperlink{classcslt_1_1String}{String}} is considered less
\end{DoxyItemize}
\end{DoxyParagraph}
\begin{DoxyParagraph}{Error conditions\+:}
Returns -\/128 if\+:
\begin{DoxyItemize}
\item str parameter is nullptr
\item Internal buffer (str\+\_\+) is null (corrupted \mbox{\hyperlink{classcslt_1_1String}{String}})
\end{DoxyItemize}
\end{DoxyParagraph}
\begin{DoxyParagraph}{Performance\+:}

\begin{DoxyItemize}
\item O(n) where n = min(this-\/$>$\mbox{\hyperlink{classcslt_1_1String_acad01b0064c0fba1f1fbbadc6b2f625d}{size()}}, strlen(str))
\item Early termination on first difference
\item Single pass, no allocation
\end{DoxyItemize}
\end{DoxyParagraph}
\begin{DoxyParagraph}{Thread safety\+:}

\begin{DoxyReturn}{Returns}
int8\+\_\+t comparison result\+:
\begin{DoxyItemize}
\item -\/1 if this string is less than other
\item 0 if strings are equal
\item 1 if this string is greater than other
\item -\/128 if either string\textquotesingle{}s buffer is null (error sentinel)

Performs lexicographic comparison of two \mbox{\hyperlink{classcslt_1_1String}{String}} objects. This is the preferred method for comparing \mbox{\hyperlink{classcslt_1_1String}{String}} instances as it uses the stored length information for optimization.
\end{DoxyItemize}
\end{DoxyReturn}
Comparison algorithm\+:
\begin{DoxyItemize}
\item Compares min(this-\/$>$len\+\_\+, other.\+len\+\_\+) characters byte-\/by-\/byte
\item Uses unsigned byte comparison (0-\/255)
\item If all common characters match, compares lengths
\item Early termination on first difference
\end{DoxyItemize}

Return value interpretation\+:
\begin{DoxyItemize}
\item -\/1\+: This string sorts before other (this $<$ other)
\item 0\+: Strings are identical in content and length
\item 1\+: This string sorts after other (this $>$ other)
\item -\/128\+: \mbox{\hyperlink{classcslt_1_1Error}{Error}} condition (null internal buffer)
\end{DoxyItemize}

\begin{DoxyParagraph}{Advantages over C-\/string comparison\+:}

\begin{DoxyItemize}
\item No need to scan for null terminator in other
\item Handles embedded nulls correctly (compares up to logical length)
\item More efficient for long strings with early differences
\item Type-\/safe (no risk of comparing with invalid C-\/string)
\end{DoxyItemize}
\end{DoxyParagraph}
\begin{DoxyParagraph}{Performance\+:}

\begin{DoxyItemize}
\item O(n) where n = min(this-\/$>$\mbox{\hyperlink{classcslt_1_1String_acad01b0064c0fba1f1fbbadc6b2f625d}{size()}}, other.\+size())

\item Early termination on first difference
\item Can be SIMD-\/optimized (see implementation notes)
\end{DoxyItemize}

Appends the contents of str to the end of the current string. The function automatically handles buffer growth when necessary, using the allocator\textquotesingle{}s realloc() method if available, or falling back to allocate-\/copy-\/free pattern.

Key behaviors\+:
\begin{DoxyItemize}
\item Always maintains null termination
\item Detects and handles self-\/aliasing (when str points within current buffer)
\item Prevents size\+\_\+t overflow in length calculations
\item Returns immediately if str is empty (no-\/op, returns true)
\item Grows buffer capacity as needed
\end{DoxyItemize}

Buffer growth strategy\+:
\begin{DoxyItemize}
\item If allocator supports realloc(), uses in-\/place reallocation
\item Otherwise, allocates new buffer, copies data, and frees old buffer
\item Pre-\/allocating capacity via \mbox{\hyperlink{classcslt_1_1String_ab1efd0bf9fe05c2af789e5fb74f7223c}{init()}} can reduce reallocations
\end{DoxyItemize}

\begin{DoxyParagraph}{Self-\/aliasing\+:}
The function safely handles cases where str points to a substring of the current buffer. It detects this condition and creates a temporary copy before any reallocation occurs.
\end{DoxyParagraph}
\begin{DoxyParagraph}{Error conditions\+:}
Returns false if\+:
\begin{DoxyItemize}
\item str is nullptr
\item Internal buffer is null (corrupted \mbox{\hyperlink{classcslt_1_1String}{String}})
\item \mbox{\hyperlink{classcslt_1_1Allocator}{Allocator}} is null
\item Length overflow would occur (len + strlen(str) + 1 $>$ SIZE\+\_\+\+MAX)
\item Memory allocation fails during buffer growth
\end{DoxyItemize}
\end{DoxyParagraph}
\begin{DoxyParagraph}{Thread safety\+:}
Not thread-\/safe. External synchronization required for concurrent access.
