\doxysubsection{Detailed Description}
Allocator-\/backed string container. 

Provides a string container that uses custom allocators for memory management. The string and its internal buffer are both allocated through the provided allocator.

Key features\+:
\begin{DoxyItemize}
\item Custom allocator support (heap, arena, buddy, slab, etc.)
\item Null-\/terminated C-\/string compatibility
\item Capacity management with optional pre-\/allocation
\item Safe truncation when capacity is insufficient
\item RAII-\/based memory management through init factory functions
\end{DoxyItemize}

Usage pattern\+:
\begin{DoxyItemize}
\item Must be initialized via static factory function \doxylink{classcslt_1_1String_ab1efd0bf9fe05c2af789e5fb74f7223c}{init()}
\item Cannot be constructed directly (private constructor)
\item Automatically manages both string object and buffer memory
\item Cleaned up through custom deleter
\end{DoxyItemize}

\item Null terminators are considered for the C-\/string parameter
\item The \doxylink{classcslt_1_1String}{String}\textquotesingle{}s logical length (len\+\_\+) determines comparison extent

\end{DoxyItemize}

\begin{DoxyParams}{Parameters}

\begin{DoxyReturn}{Returns}
true if concatenation succeeded, false on failure
\end{DoxyReturn}
Appends the contents of str to the end of the current string. The function automatically handles buffer growth when necessary, using the allocator\textquotesingle{}s realloc() method if available, or falling back to allocate-\/copy-\/free pattern.

Key behaviors\+:
\begin{DoxyItemize}
\item Always maintains null termination
\item Detects and handles self-\/aliasing (when str points within current buffer)
\item Prevents size\+\_\+t overflow in length calculations
\item Returns immediately if str is empty (no-\/op, returns true)
\item Grows buffer capacity as needed
\end{DoxyItemize}

Buffer growth strategy\+:
\begin{DoxyItemize}
\item If allocator supports realloc(), uses in-\/place reallocation
\item Otherwise, allocates new buffer, copies data, and frees old buffer
\item Pre-\/allocating capacity via \doxylink{classcslt_1_1String_ab1efd0bf9fe05c2af789e5fb74f7223c}{init()} can reduce reallocations
\end{DoxyItemize}

\begin{DoxyParagraph}{Self-\/aliasing\+:}
The function safely handles cases where str points to a substring of the current buffer. It detects this condition and creates a temporary copy before any reallocation occurs.
\end{DoxyParagraph}
\begin{DoxyParagraph}{Error conditions\+:}
Returns false if\+:
\begin{DoxyItemize}
\item str is nullptr
\item Internal buffer is null (corrupted \doxylink{classcslt_1_1String}{String})
\item \doxylink{classcslt_1_1Allocator}{Allocator} is null
\item Length overflow would occur (len + strlen(str) + 1 \texorpdfstring{$>$}{>} SIZE\+\_\+\+MAX)
\item Memory allocation fails during buffer growth
\end{DoxyItemize}
\end{DoxyParagraph}
\begin{DoxyParagraph}{Thread safety\+:}
Not thread-\/safe. External synchronization required for concurrent access.
\end{DoxyParagraph}

\begin{DoxyParams}{Parameters}

{\em begin} & Optional start of search window (default\+: start of string) \\

{\em end} & Optional end of search window (default\+: end of string)\\

Scans the window in reverse order (rightmost match first) and removes each occurrence by shifting the suffix left with memmove. After each removal the logical length (\doxylink{classcslt_1_1String_acad01b0064c0fba1f1fbbadc6b2f625d}{size()}) is reduced accordingly and the window end is clamped to the new used region before the next search.

Trailing-\/space elision\+: if the character immediately following a match is an ASCII space, that space is consumed along with the match. This keeps word-\/list strings tidy when a word is dropped from the middle.

The method is a no-\/op if\+:
\begin{DoxyItemize}
\item str\+\_\+ or substring is null
\item substring is empty
\item The window is empty or inverted
\item Either range pointer falls outside the allocation
\end{DoxyItemize}
