\doxysubsection{Detailed Description}
Allocator-\/backed string container. 

Provides a string container that uses custom allocators for memory management. The string and its internal buffer are both allocated through the provided allocator.

Key features\+:
\begin{DoxyItemize}
\item Custom allocator support (heap, arena, buddy, slab, etc.)
\item Null-\/terminated C-\/string compatibility
\item Capacity management with optional pre-\/allocation
\item Safe truncation when capacity is insufficient
\item RAII-\/based memory management through init factory functions
\end{DoxyItemize}

Usage pattern\+:
\begin{DoxyItemize}
\item Must be initialized via static factory function \mbox{\hyperlink{classcslt_1_1String_ab1efd0bf9fe05c2af789e5fb74f7223c}{init()}}
\item Cannot be constructed directly (private constructor)
\item Automatically manages both string object and buffer memory
\item Cleaned up through custom deleter
\end{DoxyItemize}

Creates a new \mbox{\hyperlink{classcslt_1_1String}{String}} instance using the provided allocator.

Capacity semantics\+:
\begin{DoxyItemize}
\item If capacity\+\_\+bytes is 0, the allocation defaults to exactly the length of cstr plus space for the null terminator
\item If capacity\+\_\+bytes is non-\/zero, the container allocates (capacity\+\_\+bytes + 1) bytes to guarantee space for the terminator
\item If the requested capacity is smaller than the source string length, the stored string is truncated to fit and always null-\/terminated
\end{DoxyItemize}

Memory allocation\+:
\begin{DoxyItemize}
\item Both the \mbox{\hyperlink{classcslt_1_1String}{String}} object and its internal buffer are allocated through the provided allocator
\item The allocator reference is stored for cleanup
\item Memory must later be released through the \mbox{\hyperlink{classcslt_1_1StringDeleter}{String\+Deleter}}
\end{DoxyItemize}

\begin{DoxyParagraph}{Error conditions\+:}

\begin{DoxyItemize}
\item \mbox{\hyperlink{classcslt_1_1ArgumentError}{Argument\+Error}} if cstr is nullptr
\item Propagates any allocation errors from the allocator (typically \mbox{\hyperlink{classcslt_1_1MemoryError}{Memory\+Error}})
\end{DoxyItemize}
