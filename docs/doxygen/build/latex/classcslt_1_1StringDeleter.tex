\doxysubsection{Detailed Description}
Custom deleter for \mbox{\hyperlink{classcslt_1_1String}{String}} instances. 

Implements proper cleanup for \mbox{\hyperlink{classcslt_1_1String}{String}} objects by\+:
\begin{DoxyEnumerate}
\item Freeing the internal character buffer
\item Freeing the \mbox{\hyperlink{classcslt_1_1String}{String}} object itself Both operations use the allocator stored in the \mbox{\hyperlink{classcslt_1_1String}{String}}.
\end{DoxyEnumerate}

This deleter is used with \mbox{\hyperlink{classcslt_1_1UniquePtr}{Unique\+Ptr}} to provide RAII semantics.
