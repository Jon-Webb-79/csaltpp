\doxysubsection{Detailed Description}
Custom deleter for \doxylink{classcslt_1_1String}{String} instances. 

Implements proper cleanup for \doxylink{classcslt_1_1String}{String} objects by\+:
\begin{DoxyEnumerate}
\item Freeing the internal character buffer
\item Freeing the \doxylink{classcslt_1_1String}{String} object itself Both operations use the allocator stored in the \doxylink{classcslt_1_1String}{String}.
\end{DoxyEnumerate}

This deleter is used with \doxylink{classcslt_1_1UniquePtr}{Unique\+Ptr} to provide RAII semantics.
