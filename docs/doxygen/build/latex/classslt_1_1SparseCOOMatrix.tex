\subsubsection*{template$<$typename T$>$\newline
class slt\+::\+Sparse\+COOMatrix$<$ T $>$}

Sparse Coordinate (COO) Matrix class. 

This class represents a sparse matrix using the Coordinate List (COO) format. Each non-\/zero element of the matrix is stored as a {\ttfamily \mbox{\hyperlink{structslt_1_1Triplet}{Triplet}}} object, containing (row, column, value).

The matrix supports two internal insertion modes\+:
\begin{DoxyItemize}
\item $\ast$$\ast$\+Fast insert mode ({\ttfamily fast\+\_\+set == true})$\ast$$\ast$\+: Triplets are appended to the internal vector in O(1) time. This allows very efficient construction of the matrix, but requires the user to call {\ttfamily \mbox{\hyperlink{classslt_1_1SparseCOOMatrix_af2dd10fb10528bb4abee019204d3fc64}{finalize()}}} before performing retrievals such as {\ttfamily \mbox{\hyperlink{classslt_1_1SparseCOOMatrix_a8060856161b5989ab2f30b87d8d5bf71}{get()}}} or binary searches.
\item $\ast$$\ast$\+Sorted mode ({\ttfamily fast\+\_\+set == false})$\ast$$\ast$\+: Triplets are kept sorted by (row, column), allowing efficient retrieval using binary search, at the cost of slower insertions.
\end{DoxyItemize}

Supported operations\+:
\begin{DoxyItemize}
\item Insertion of new elements ({\ttfamily \mbox{\hyperlink{classslt_1_1SparseCOOMatrix_a124ffa2d3de4c59810806ee6c21838d6}{set()}}})
\item Updating existing elements ({\ttfamily \mbox{\hyperlink{classslt_1_1SparseCOOMatrix_a30d1204d80d8b51f20217c5af322a2da}{update()}}})
\item Element-\/wise arithmetic with other \mbox{\hyperlink{classslt_1_1SparseCOOMatrix}{Sparse\+COOMatrix}} or \mbox{\hyperlink{classslt_1_1DenseMatrix}{Dense\+Matrix}}
\item Scalar operations (+, -\/, $\ast$)
\item Conversion to \mbox{\hyperlink{classslt_1_1DenseMatrix}{Dense\+Matrix}}
\item Iteration over stored triplets ({\ttfamily \mbox{\hyperlink{classslt_1_1SparseCOOMatrix_a40f66827dc6598f748825018494bd37b}{begin()}}}, {\ttfamily \mbox{\hyperlink{classslt_1_1SparseCOOMatrix_a1715d2dda083ee4f83f0ffe0fab7005c}{end()}}})
\end{DoxyItemize}

Template parameter T must be either float or double.
