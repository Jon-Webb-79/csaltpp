\doxysubsection{Detailed Description}
Custom deleter for \doxylink{classcslt_1_1ArenaAllocator}{Arena\+Allocator} unique pointers. 

This deleter properly cleans up \doxylink{classcslt_1_1ArenaAllocator}{Arena\+Allocator} instances created by factory methods (Heap, Stack, Sub\+Arena). It\+:
\begin{DoxyEnumerate}
\item Calls the arena\textquotesingle{}s destructor (frees additional chunks)
\item Frees the base memory only if the arena owns it (DYNAMIC only)
\end{DoxyEnumerate}

Memory ownership\+:
\begin{DoxyItemize}
\item DYNAMIC (Heap)\+: Owns memory → frees with \+::operator delete
\item STATIC (Stack)\+: User owns buffer → doesn\textquotesingle{}t free
\item SUB (Sub\+Arena)\+: Parent owns memory → doesn\textquotesingle{}t free 
\end{DoxyItemize}
