This custom deleter is invoked when a Unique\+Ptr$<$\+Buddy\+Allocator, Buddy\+Deleter$>$ goes out of scope or is explicitly reset. It performs complete and ordered cleanup of all resources owned by a \doxylink{classcslt_1_1BuddyAllocator}{Buddy\+Allocator} instance.

\doxylink{classcslt_1_1BuddyAllocator}{Buddy\+Allocator} always owns all of its internal resources. Unlike other allocator types, it does not support borrowed memory pools or user-\/provided backing storage. As a result, cleanup behavior is unconditional and uniform.

{\bfseries{Cleanup sequence\+:}}
\begin{DoxyEnumerate}
\item Release the OS-\/backed memory pool used for allocations (via Buddy\+Allocator\+::os\+\_\+free)
\item Free the free-\/lists array allocated during initialization
\item Invoke the \doxylink{classcslt_1_1BuddyAllocator}{Buddy\+Allocator} destructor
\item Free the \doxylink{classcslt_1_1BuddyAllocator}{Buddy\+Allocator} object itself (via \+::operator delete)
\end{DoxyEnumerate}

This ordering guarantees that all allocator-\/internal state remains valid for the duration of the destructor and that no memory leaks occur.

\begin{DoxyNote}{Note}
This deleter is noexcept and never throws exceptions during cleanup.

Passing a null pointer is safe and results in an immediate no-\/op.

All outstanding allocations become invalid once this deleter is invoked. Accessing previously allocated memory after destruction results in undefined behavior.

Users must not call this function directly. It is automatically invoked by \doxylink{classcslt_1_1UniquePtr}{Unique\+Ptr} when the \doxylink{classcslt_1_1BuddyAllocator}{Buddy\+Allocator} goes out of scope or is reset.
\end{DoxyNote}
\begin{DoxyWarning}{Warning}
Pointers returned by this \doxylink{classcslt_1_1BuddyAllocator}{Buddy\+Allocator} must not be freed or accessed after the allocator has been destroyed.
\end{DoxyWarning}
