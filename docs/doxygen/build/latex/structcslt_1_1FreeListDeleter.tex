\doxysubsection{Detailed Description}
Custom deleter for \mbox{\hyperlink{classcslt_1_1FreeListAllocator}{Free\+List\+Allocator}} unique pointers. 

This deleter properly cleans up \mbox{\hyperlink{classcslt_1_1FreeListAllocator}{Free\+List\+Allocator}} instances created by factory methods (Heap, With\+Arena, Stack). It handles the complex ownership relationships between freelists and their backing arenas\+:

Arena ownership patterns\+:
\begin{DoxyItemize}
\item {\bfseries{Heap()}}\+: Free\+List owns arena → \mbox{\hyperlink{structcslt_1_1ArenaDeleter}{Arena\+Deleter}} frees arena and memory
\item {\bfseries{With\+Arena()}}\+: Free\+List borrows arena → Arena not deleted (caller owns it)
\item {\bfseries{Stack()}}\+: Free\+List owns arena object → \mbox{\hyperlink{structcslt_1_1ArenaDeleter}{Arena\+Deleter}} destructs arena (but doesn\textquotesingle{}t free buffer, user owns it)
\end{DoxyItemize}

This custom deleter is invoked when a Unique\+Ptr$<$\+Free\+List\+Allocator$>$ goes out of scope or is explicitly reset. It handles proper cleanup of the freelist and its backing arena based on ownership semantics.

{\bfseries{Cleanup sequence\+:}}
\begin{DoxyEnumerate}
\item Extract ownership information (owns\+\_\+arena, arena, mem\+\_\+type)
\item Call $\sim$\+Free\+List\+Allocator() destructor
\item Conditionally clean up arena based on ownership and type\+:
\end{DoxyEnumerate}

{\bfseries{Heap() freelists}} (owns\+\_\+arena=true, mem\+\_\+type=DYNAMIC)\+:
\begin{DoxyItemize}
\item Calls \mbox{\hyperlink{structcslt_1_1ArenaDeleter}{Arena\+Deleter}}\{\}(arena)
\item Arena and all memory is freed back to heap
\end{DoxyItemize}

{\bfseries{With\+Arena() freelists}} (owns\+\_\+arena=false)\+:
\begin{DoxyItemize}
\item No arena cleanup performed
\item Arena remains valid for other allocators
\end{DoxyItemize}

{\bfseries{Stack() freelists}} (owns\+\_\+arena=true, mem\+\_\+type=STATIC)\+:
\begin{DoxyItemize}
\item Calls arena-\/$>$$\sim$\+Arena\+Allocator() destructor
\item Does NOT free buffer (user owns it)
\item Arena object destroyed, buffer remains valid
\end{DoxyItemize}

This deleter ensures memory is properly released for heap-\/allocated arenas while preserving user-\/owned buffers for stack-\/based freelists and borrowed arenas for shared freelists.

\begin{DoxyNote}{Note}
This is a noexcept function -\/ no exceptions are thrown during cleanup.

Null pointer is safely handled (early return, no crash).

The freelist destructor is always called before arena cleanup to ensure proper cleanup ordering.

Users should never call this directly -\/ it is automatically invoked by \mbox{\hyperlink{classcslt_1_1UniquePtr}{Unique\+Ptr}} when the freelist goes out of scope.
\end{DoxyNote}
