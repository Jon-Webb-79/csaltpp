\doxysubsection{Detailed Description}
Custom deleter for \doxylink{classcslt_1_1PoolAllocator}{Pool\+Allocator} unique pointers. 

Similar to \doxylink{structcslt_1_1ArenaDeleter}{Arena\+Deleter}, properly cleans up \doxylink{classcslt_1_1PoolAllocator}{Pool\+Allocator} instances created by factory methods. Handles ownership appropriately\+:
\begin{DoxyItemize}
\item DYNAMIC pools that own their arena\+: frees the pool and arena
\item Pools with borrowed arenas\+: only frees the pool structure
\end{DoxyItemize}

This deleter properly cleans up \doxylink{classcslt_1_1PoolAllocator}{Pool\+Allocator} instances created by factory methods (\doxylink{classcslt_1_1Heap}{Heap}, With\+Arena, Stack). It handles the complex ownership relationships between pools and their backing arenas\+:


\begin{DoxyEnumerate}
\item Calls the pool\textquotesingle{}s destructor (cleans up pool state)
\item Conditionally destroys the arena based on ownership
\end{DoxyEnumerate}

Arena ownership patterns\+:
\begin{DoxyItemize}
\item {\bfseries{Heap()}}\+: Pool owns arena → \doxylink{structcslt_1_1ArenaDeleter}{Arena\+Deleter} frees arena and memory
\item {\bfseries{With\+Arena()}}\+: Pool borrows arena → Arena not deleted (caller owns it)
\item {\bfseries{Stack()}}\+: Pool owns arena object → \doxylink{structcslt_1_1ArenaDeleter}{Arena\+Deleter} destructs arena (but doesn\textquotesingle{}t free buffer, user owns it)
\end{DoxyItemize}

The deleter respects the {\ttfamily owns\+\_\+arena\+\_\+} flag to determine whether the pool created its own arena (Heap/\+Stack) or borrowed one (With\+Arena).

\begin{DoxyNote}{Note}
This deleter is noexcept and safe to call with nullptr. 
\end{DoxyNote}
