class cslt\+::\+String\+Key$<$ N $>$}
Fixed-\/size trivially copyable string key for use with Dict$<$\+K, V$>$ 

{\ttfamily \doxylink{classcslt_1_1String}{cslt\+::\+String}} cannot be used directly as a \doxylink{classcslt_1_1Dict}{Dict} key because its private destructor and deleted copy operations make it non-\/trivially-\/copyable — a requirement enforced by \doxylink{classcslt_1_1Dict}{Dict}\textquotesingle{}s {\ttfamily static\+\_\+assert}. {\ttfamily \doxylink{structcslt_1_1StringKey}{String\+Key}\texorpdfstring{$<$}{<}N\texorpdfstring{$>$}{>}} solves this by copying the string content into a fixed-\/size stack buffer of {\ttfamily N} bytes (including the null terminator), making the type trivially copyable and zero-\/cost to hash.

The template parameter {\ttfamily N} is the total buffer size {\bfseries{including}} the null terminator, so a {\ttfamily \doxylink{structcslt_1_1StringKey}{String\+Key}\texorpdfstring{$<$}{<}32\texorpdfstring{$>$}{>}} stores up to 31 printable characters. Strings longer than {\ttfamily N-\/1} characters are silently truncated.

{\ttfamily operator==} uses {\ttfamily std\+::strncmp} so \doxylink{classcslt_1_1Dict}{Dict}\textquotesingle{}s equality detection trait picks it up automatically — no custom comparator is needed.

Recommended sizes\+:
\begin{DoxyItemize}
\item {\ttfamily \doxylink{structcslt_1_1StringKey}{String\+Key}\texorpdfstring{$<$}{<}32\texorpdfstring{$>$}{>}} — short identifiers, sensor names, config keys
\item {\ttfamily \doxylink{structcslt_1_1StringKey}{String\+Key}\texorpdfstring{$<$}{<}64\texorpdfstring{$>$}{>}} — typical dictionary words, variable names
\item {\ttfamily \doxylink{structcslt_1_1StringKey}{String\+Key}\texorpdfstring{$<$}{<}128\texorpdfstring{$>$}{>}} — sentences, file names
\item {\ttfamily \doxylink{structcslt_1_1StringKey}{String\+Key}\texorpdfstring{$<$}{<}256\texorpdfstring{$>$}{>}} — file paths, long descriptors
\end{DoxyItemize}
