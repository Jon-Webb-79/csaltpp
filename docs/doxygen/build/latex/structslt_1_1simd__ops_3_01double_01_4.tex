\doxysubsection{Detailed Description}
SIMD-\/accelerated operations for arrays of double values. 

This specialization of {\ttfamily \mbox{\hyperlink{structslt_1_1simd__ops}{simd\+\_\+ops}}} provides vectorized operations for 64-\/bit floating-\/point data using SIMD extensions such as AVX-\/512, AVX2, SSE (2–4.1), NEON (AArch64), SVE, and SVE2, when available.

Each method applies a SIMD-\/optimized version of a common numerical operation on double-\/precision floating-\/point arrays. Scalar fallback behavior is managed externally.

Supported operations include\+:
\begin{DoxyItemize}
\item Element-\/wise arithmetic (add, subtract, multiply)
\item Scalar arithmetic (add, subtract, multiply, divide)
\item Data copy
\item Magnitude squared computation
\end{DoxyItemize}

These methods are dispatched at compile time using architecture-\/specific flags, ensuring optimal performance where supported.

\begin{DoxyNote}{Note}
SIMD instruction sets for double precision may require specific compile-\/time flags (e.\+g., {\ttfamily -\/mavx2}, {\ttfamily -\/msse2}, {\ttfamily -\/march=armv8-\/a+sve}, etc.).
\end{DoxyNote}
