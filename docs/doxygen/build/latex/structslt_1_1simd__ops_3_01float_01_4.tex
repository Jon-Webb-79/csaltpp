\doxysubsection{Detailed Description}
SIMD-\/accelerated operations for arrays of float values. 

This specialization of {\ttfamily \mbox{\hyperlink{structslt_1_1simd__ops}{simd\+\_\+ops}}} provides high-\/performance operations using SIMD instruction sets such as AVX-\/512, AVX2, SSE (2–4.1), NEON, SVE, and SVE2 when available on the target architecture.

Each method performs a vectorized computation on arrays of 32-\/bit float values, falling back to scalar logic if no SIMD backend is available (handled in the calling code).

Supported operations include\+:
\begin{DoxyItemize}
\item Element-\/wise addition, subtraction, multiplication
\item Scalar addition, subtraction, multiplication, division
\item Memory copy
\item Magnitude squared computation
\end{DoxyItemize}

This struct is intended to be used via compile-\/time dispatch through {\ttfamily \mbox{\hyperlink{structslt_1_1simd__traits}{simd\+\_\+traits}}$<$T$>$\+::supported} to ensure compatibility across platforms.

\begin{DoxyNote}{Note}
Instruction set support must be enabled at compile time using compiler flags such as {\ttfamily -\/mavx2}, {\ttfamily -\/msse4.\+1}, {\ttfamily -\/march=armv8-\/a+simd}, etc.
\end{DoxyNote}
